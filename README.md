# GradeMaster

Статический набор калькуляторов оценок, GPA и посещаемости. Интерфейс поддерживает русский, казахский и английский языки.

## Запуск

Откройте `index.html` или запустите локальный сервер из корня проекта:

```powershell
python -m http.server 8080
```

Сайт будет доступен на `http://localhost:8080`. Сборка для статических страниц не нужна. Такой сервер не запускает Vercel-функцию `api/telegram.js`.

## Проверки

Для тестов используйте Node.js 22.12+ или 24+:

```powershell
npm ci
npm test
npm audit
```

Тесты используют локальный DOM и подмену сети; настоящие сообщения обратной связи не отправляются.

## Локализация

Переводы находятся в `js/language.js`, общий контроллер языка и темы — в `js/localization.js`. Для новых строк добавляйте одинаковые ключи во все три словаря. Подстановки вроде `{number}` должны совпадать между языками. Пользовательские значения не следует добавлять в HTML без экранирования.
