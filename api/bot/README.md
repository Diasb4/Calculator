# GradeMaster Telegram Bot (@Reply_1423bot)

Telegram-бот для проекта **GradeMaster**: мгновенный расчёт оценок, прогноз на экзамен (файнал), расчёт допустимых пропусков, запуск веб-калькулятора (Web App) и система ответов на обращения студентов.

---

## 🚀 Быстрый запуск

Бот написан на чистом Node.js и **не требует установки тяжёлых сторонних библиотек**.

```bash
cd bot
node bot.js
```
или
```bash
npm start
```

---

## ⚙️ Переменные окружения (опционально)

Вы можете переопределить настройки через переменные окружения:

- `TELEGRAM_BOT_TOKEN` — токен бота (по умолчанию уже настроен на `@Reply_1423bot`).
- `TELEGRAM_CHAT_ID` — ваш числовой Chat ID администратора.
- `WEBAPP_URL` — ссылка на сайт GradeMaster (по умолчанию: `https://calculator-not-404.vercel.app`).

## 📋 Возможности и команды бота

| Команда | Описание | Пример |
|---|---|---|
| `/start` | Главное меню, запуск бота и кнопки | `/start` |
| `/calc <регмид> <регэнд>` | Расчёт РегТерма и прогноз баллов на файнал для обычной и повышенной стипендии | `/calc 80 85` |
| `/calc <регмид> <регэнд> <файнал>` | Полный расчёт итогового балла с вердиктом (стипендия / пересдача / летник) | `/calc 80 85 90` |
| `/att <пар в неделю>` | Расчёт допустимого количества пропусков за 10 недель (порог 30%) | `/att 3` |
| `/id` | Показывает ваш Telegram Chat ID | `/id` |
| `/reply <chat_id> <текст>` | Отправить ответ студенту на его обращение | `/reply 123456789 Спасибо за отзыв!` |
| `/help` | Подробная справка по всем функциям | `/help` |

---

## 💬 Функция «Ответ на обращение» (Reply)

1. Когда студент пишет сообщение боту, оно автоматически пересылается администратору (`ADMIN_CHAT_ID`).
2. Администратор может ответить **двумя способами**:
   - **Способ 1 (самый удобный)**: Просто сделать **Reply (Ответить)** на сообщение от бота в Telegram.
   - **Способ 2**: Отправить команду `/reply <chat_id> <текст ответа>`.
3. Бот мгновенно доставит ответ студенту в его личный чат с ботом.
