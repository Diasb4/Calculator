# GradeMaster Telegram Bot (@aitugrademaster_bot)

Полноценная автономная замена веб-сайта **GradeMaster** прямо внутри Telegram.

Бот включает все калькуляторы системы оценивания университета: пошаговые интерактивные визарды, экспресс-команды в одну строку, систему прогноза экзаменов и стипендий, визуальные шкалы посещаемости и закрытую панель администратора.

---

## 🚀 Возможности для студентов

1. **🚀 Калькулятор итоговой оценки (`/calc`)**:
   - Пошаговый мастер или быстрая команда: `/calc 80 85` (прогноз на экзамен) или `/calc 80 85 90` (точный расчёт).
   - Автоматический расчёт РегТерма (60%), Файнала (40%), проверка порогов допуска (25 баллов) и прогноз на обычную (70+) и повышенную (90+) стипендии.

2. **📊 Калькулятор GPA за триместр (`/gpa`)**:
   - Ввод оценок в процентах или буквенных эквивалентах (A, B+, C и т.д.) с весом кредитов каждого предмета.
   - Пример: `/gpa 90 3, 85 4, 95 2` или интерактивный ввод через кнопку.

3. **📈 Кумулятивный GPA (`/cgpa`)**:
   - Расчёт общего GPA за все пройденные триместры/семестры с учётом кредитов.
   - Пример: `/cgpa 3.5 15, 3.8 20` (или `/cumulative`).

4. **📋 Калькулятор посещаемости (`/att`)**:
   - 10-недельная шкала с порогом 30%.
   - Визуальный эмодзи-индикатор риска `[🟢🟢🟡🔴⚪]` и расчёт остатка безопасных пропусков.
   - Пример: `/att 3` или `/att 3 2` (если 2 пары уже пропущены).

5. **🔄 Конвертер оценок в GPA (`/convert`)**:
   - Мгновенный перевод баллов в буквенную шкалу (A, A-, B+ ...), ECTS и GPA (0.00 - 4.00).
   - Пример: `/convert 88`.

6. **💬 Поддержка и обратная связь**:
   - Студент может задать вопрос или оставить отзыв прямо боту.

## ⚙️ Панель Администратора (Скрыта от обычных пользователей)

> [!IMPORTANT]
> Кнопка «⚙️ Панель Администратора» и команды `/admin`, `/broadcast` **полностью скрыты и защищены**. Обычные пользователи видят только понятную инструкцию и калькуляторы.

Функции для администратора (`TELEGRAM_CHAT_ID`):
- `/admin` — диагностика состояния бота, переменных окружения и активных сессий.
- `/broadcast <сообщение>` — рассылка уведомлений всем пользователям бота.
- Ответ на обращение студента: прямой ответ через Telegram Reply на пересланное сообщение или `/reply <chat_id> <текст>`.

## 🛠 Настройка и развёртывание на Vercel

1. **Переменные окружения в Vercel** (`Settings -> Environment Variables`):
   - `TELEGRAM_BOT_TOKEN`: токен вашего бота из `@BotFather`.
   - `TELEGRAM_CHAT_ID`: ваш числовой Chat ID (узнайте через `/id` у бота).
   - `WEBAPP_URL`: URL вашего развёртывания (например, `https://calculator-not-404.vercel.app`).
   - `TELEGRAM_SECRET_TOKEN`: (опционально) секретный токен вебхука.

2. **Активация Webhook**:
   После деплоя на Vercel просто откройте в браузере:
   ```
   https://<ваш-проект>.vercel.app/api/bot?setup=1
   ```
   Бот автоматически свяжется с Telegram API и настроит вебхук.
